Destroy Order Dependency

Service accounts must be destroyed in reverse phase order to avoid stale IAM references:

Phase 4
dashboard SA
→
Phase 3
bq-loader + invoker
→
Phase 2
processor + invoker
→
Phase 1
cloud-build + others

Cloud Build SA (Phase 1) must be destroyed last since all phases depend on it for image builds.
